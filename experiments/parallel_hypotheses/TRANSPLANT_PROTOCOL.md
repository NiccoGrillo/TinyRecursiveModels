# PH1 secondary counterfactual message check

Specified while endpoint training ran, before reading its logs, summaries or predictions. This exploratory test checks for intermediate-value-specific routing in two separately learned roles. It does not name a role from its outputs. For each nonidentity-G development recipient, choose two donors with the same G, q and Hamming distance from the recipient's four-entry F. The placebo donor has the same F(q); the active donor has different F(q). Choose lexicographically first matched pair; drop recipient if no pair exists. Match on visible inputs only, without looking at outcomes. Intervene on both second-round messages simultaneously using donor first-round states while preserving both recipient self states and all recipient readout. Score placebo and active transplants at recipient target, and active transplant at donor target. Donor-target adoption is interpretable only alongside intact recipient/donor performance and placebo stability. A reduction in accuracy under unstructured shuffling or clamping alone has no content-specific interpretation. Publish donor IDs and all outcomes; subgroup counts are descriptive, sharing recipients and donors across seeds.
