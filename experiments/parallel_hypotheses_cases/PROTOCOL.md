# PH2 preregistration · 27 November 2026

Each input describes two equally admissible worlds A,B by fully visible four-row permutation tables F_A,F_B, query symbol q, and a new visible two-row answer table R. The model must output R[e], where e=1 if the two possible results F_A(q),F_B(q) have equal parity, otherwise e=0. No internal or branch labels enter training. This is a constructed possible-world comparison with an arbitrary downstream operation and explicit world boundaries. It tests whether evaluating both assumptions in parallel offers anything beyond executing the same comparisons serially. It does not test discovery of assumptions. Negative control R[0]=R[1] requires no comparison. All 16 ordered R tables (entries 0..3) and all queries are balanced. Example F_A=(2,0,3,1),F_B=(0,2,1,3),q=0 gives 2 and 0, hence e=1. With R=(3,1) output 1. Changing F_B to (1,2,0,3) changes the answer to 3 while A is fixed.

Group by unordered pair of permutation IDs, including identical pairs, then randomly shuffle 300 groups with PCG64(9701); 200 train/50 development/50 reserved. Retain both orderings where distinct in each group; no reserve labels generated. No discovery on previous Sudoku or PH1 holdouts. The two conditional executions use the world indicator to select the corresponding table from the input. Both approaches get the same interface; this supplied factorization and the final addressable answer table are strong task-specific biases.

## Models and rivals

A shared learned address (softmax of a 4-by-4 matrix row picked by visible q) reads each world table into a learned 8-dimensional symbol embedding. This is an explicit lookup interface. The join uses a symmetric feature vector (sum and elementwise product of the two reads), an affine/tanh layer of width 16 and a scalar sigmoid, then uses the resulting probability as a soft address in R. Train only end-to-end output negative log likelihood. Compare exact serial evaluation of each world using the same trained weights and readout: by substitution the logits and work coincide mathematically, while independent world reads can overlap in the parallel schedule. Check max absolute difference and exact answer equality on every dev row; time both schedules.

Late-selection challenger uses the same world executor and symmetric network to predict a mixing weight. Each world proposes its own soft address from its state and a role-specific bias. The final address is their convex mixture. This expressive rival may use opposed constant candidate addresses and let the selector compute the whole answer. It is separately trained, with a few extra parameters and arithmetic; report that cost. Such a win defeats the claim that newly computed answers are necessary here. Train paired seeds 31,47,83 (shared parameters identical init), Adam 0.01, 1200 updates of batch 128, identical draws with replacement. If any train accuracy improves >=2 percentage points between 800 and 1200, extend all to 2400. No development feedback controls training. Train curves every 400 steps.

Primary endpoint is paired mean dynamic join minus learned late-selection exact accuracy on unseen nonconstant-R dev instances, equally weighting unordered pairs; 95% percentile bootstrap over 50 groups, fixed three seeds, RNG 9703, 2000 draws. Proceed toward a learned joint-answer advantage only if >5 pp mean, all seeds positive, lower bound >0, and >=90% train exact for join; parity with serial bounds any claim to expressing a join without extra serial world executions. If ceiling for both, close the new-answer claim on this task. The programmatic reference requires two local lookups, parity equality, then one downstream lookup. Its attainable accuracy is 100%. Classify both models below 80% training accuracy as insufficient learning. Record per-instance predictions, candidate and oracle-selector scores, model parameters, learned MACs, training time, batch-one and batched inference timings, all hashes. 

## Localized intervention

For each nonconstant-R dev row, choose a dev donor sharing A, q, R whose B answer has opposite parity, deterministically smallest B ID. Transplant B's read state only; a recipient's A and R remain fixed. A correct output must switch to the donor target. Match a same-parity placebo when possible, smallest distinct B. Report eligible denominator, both-target correct conditional counts and change rates. This checks the explicitly localized wire; table lookup, world masking, and access to R after the merge are structural priors. No claims of latent interpretation follow from the wire test.
