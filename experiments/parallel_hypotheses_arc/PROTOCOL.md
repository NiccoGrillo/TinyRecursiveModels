# Frozen ARC-AGI-1 development bridge

The decision is whether spatial symmetry plus a global color map is a credible shortcut on public tasks and how much that family covers. This is a diagnostic baseline. The primary endpoint is the fraction of all 400 official public training tasks for which the single full-fit prediction solves every query exactly. An abstention is a failure. Use fchollet/ARC-AGI revision 399030444e0ab0cc8b4e199870fb20b863846f34, data/training only. Hash the original task bytes. There are no augmentations, fitted weights, task-specific rules or external labels.

Enumerate geometries in order: identity, clockwise 90, 180, 270, left-right reflection, then the three clockwise rotations of that reflection. For each, infer a single color table from aligned demonstration cells. Reject shape mismatches and inconsistent mappings. Unseen colors map to themselves. Full-fit ranks exact candidates by fewest changed color entries then geometry order. A second policy ranks the same exact candidates by the number of exactly predicted leave-one-demonstration-out targets, then uses the same tie breaks. Refit the selected geometry using all demonstrations. Consume test inputs only after selection. One output per query. One result per original task.

Report coverage, full and leave-one-out exact, paired wins/losses, overlap with identity geometry and identity recoloring, and per-task candidate counts, choices, prediction hashes and outcomes. Secondary leave-one-demonstration-out family recovery averages within task then across tasks and includes abstentions. Intervals for task proportions use Wilson intervals as descriptive exchangeable-task approximations. No change in policy after viewing scores. Enumeration is handwritten; this tests whether the family can be sufficient, never whether a model learned the family. Query labels are used only for the outer score.
