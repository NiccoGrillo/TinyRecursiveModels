# Prior-art audit, 27 November 2026

All external performance figures here come from the authors. I inspected methods and release paths. I did not execute external checkpoints. The benchmarks have different training sets, selection policies, stopping rules and units of work. Their reported figures do not establish a common ranking.

## Direct rivals for the first experiments

- In the two-table experiment, a single memory query can retrieve the first result and index the second table. In Sukhbaatar et al., the hop reads a softmax-weighted value sum, adds it to the current query, and queries unchanged keys again. The model uses an answer loss. This solution pays for multiple reads without a private candidate trajectory. The explicit two-lookup program is the ceiling when table schemas are supplied. For a learned rival, provide the same row identity and table membership available from input position, and measure generalization when symbol permutations and queries change. [End-To-End Memory Networks, §2, Eqs. 1–3](https://proceedings.neurips.cc/paper/2015/file/8fb21ee7a2207526da55a679f0332de2-Paper.pdf)
- Permutation composition admits multiple algorithms with the same answer. The state-tracking study differentiates serial and associative computation by intervening on activations from paired prefixes. In this project's toy, both slots have the complete input, and initial encoders may encode both operations. Clamping an updated peer to an initial peer intervenes on both content and activation distribution. A trained static control addresses a capacity/optimization question, while a matched task interchange would test which information the dynamic model actually transmits. [State-tracking study, §§3–4](https://arxiv.org/abs/2503.02854)
- GRAM makes stochastic recursive proposals in an HRM-like hierarchy. Training uses a posterior informed by solutions and a learned input-conditioned prior. At test time only the prior supplies stochastic latents. Parallel independent trajectories can feed majority voting or a learned reward scorer. Reusing a whole particle by selection permits future conditional computation, whereas recovering two different facts from two unsuccessful particles is a different empirical prediction. Charge scorer training, candidate trajectories and any augmentation. [Generative Recursive Reasoning, §§2.1–2.3 and App. A.4/D.2](https://arxiv.org/html/2605.19376)
- Corbett et al. make a stochastic proposal, reweight particles with an existing stopping head and resample during recursion. This updates which states receive future computation. Its matched-compute comparisons and guide interventions expose a stronger rival than selecting only the final outputs. The test for a content-sharing proposal is a gain over an online survivor policy with the same opportunities to revise. [Guided Reasoning, §§4.1–4.3, Apps. H/J](https://arxiv.org/html/2605.25230)
- Recurrent Independent Mechanisms maintain multiple recurrent module states with attention-mediated updates and communication. The shared-global-workspace model lets specialist modules write to a bottleneck and broadcasts its contents. Both precede the proposed cross-slot communication. A finding of freshness sensitivity by itself supports only this particular connection in this model/training regime. [RIMs, model and algorithm](https://openreview.net/pdf/a58297a8b9fc47b94fee061cf119f991c6bb2a87.pdf) · [Shared global workspace, architecture](https://arxiv.org/abs/2103.01197)
- Multiplex Thinking samples candidate token IDs from the same distribution and aggregates their embeddings before the next LM step. The candidates do not each execute a separate lookahead in this operation. With a shared representation and another learned update, the ability of alternative proposals to influence the next computation already exists in a different setting. Multi-Chain Reasoning explicitly uses evidence from different intermediate text chains to form a new answer in QA. Both should narrow any originality claim about combining imperfect paths. [Multiplex Thinking](https://arxiv.org/abs/2601.08808) · [MCR, §3](https://aclanthology.org/2023.emnlp-main.364/)
- For ARC demonstrations, LPN infers latent codes from observed input/output pairs, optimizes a shared program representation by sampling or gradient ascent on demonstrations, and decodes the query from that representation. The prior-art objection is substantive: learning from a consequence can amount to optimizing one program under all demonstrations. Match demonstration visibility, latent evaluation count, and include gradients in the cost. Neither a fixed rule bank nor performance on an explicitly factorized table establishes that learned private hypotheses can be composed on ARC. [Searching Latent Program Spaces, §§4.1–4.3, 5.7](https://arxiv.org/html/2411.08706) · [RobustFill, multi-example pooling and consistency decoding](https://proceedings.mlr.press/v70/devlin17a/devlin17a.pdf)

## Review evidence and interpretation

The official OpenReview links for GRAM's earlier submission title “Probabilistic Recursive Reasoning” resolve to a browser verification page here. The signed discussion reproduced on the public mirror raised selection confounding and requested pass@1 with reward ranking and voting disabled. The authors reported that this removal matched TRM on Sudoku, with the larger gains appearing under parallel sampling. Interpret this as the authors' reply at that revision. The currently available paper independently documents the prior/posterior and sampling paths and provides cost comparisons in App. D.2. The direct URLs identify the [reply](https://openreview.net/forum?id=dDjsb4dq8O&noteId=IeYlFUMhJ9), [meta-review](https://openreview.net/forum?id=dDjsb4dq8O&noteId=Q2EJ2fWwe3), and [discussion mirror consulted](https://acceptodds.com/papers/neurips2026-151067).

A release tuned on public benchmark tasks can serve as an operating-point reference. Project-held-out claims require a compatible protocol with task IDs and augmentation orbits segregated, and a method trained without those query labels. Reproduce each native policy in the release's environment before adapting it. Public TRM/FPRM and other benchmark scores are background for PH1's controlled task. None supports a measured transfer claim on ARC.
